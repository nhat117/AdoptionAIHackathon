# Dataset attribution

The test.jsonl rows originate from deepset/prompt-injections, published by deepset at https://huggingface.co/datasets/deepset/prompt-injections. The publisher declares Apache-2.0. Dataset revision and file hashes are in SOURCE.json. Rows were converted from Parquet to JSONL and given source_index identifiers; text and labels are unchanged. Predictions and metrics are newly measured experiment outputs.
