# Exactly 600 cases, 200 in each language

The user selected 600 total evaluated cases on 8 November 2026. The final design
uses 100 distinct heldout tasks from a new GPT-5-generated pool. Each task is
crossed with English, Vietnamese and Chinese lower-trust messages and peer and
director sender labels. Trusted task facts stay in English and are identical
within every six-condition task block.

| Per language | Peer | Director | Total |
|---|---:|---:|---:|
| Attack | 90 | 90 | 180 |
| Benign control | 10 | 10 | 20 |
| All cases | 100 | 100 | 200 |

Across languages: 540 attack calls and 60 benign calls = 600 target calls. There
are 90 attack task clusters and 10 benign task clusters, not 600 independent
underlying tasks. No monitor calls are part of this 600-case H1 study.

The source pool was generated by GPT-5 through Braintrust, returned model ID
`gpt-5-2025-08-07`: 500 benign project scenarios across ten domains. A fixed split
reserves 100 for development and 400 for evaluation. Twenty source batches and
the exact generation prompt, usage, model IDs and file hashes are retained.
No model outcomes or desired authority effects were generated as labels.

The user changed an already running 500-case design. Its 72 saved observations
are retained in a separate stopped collection. All 80 tasks assigned to that
design were excluded from the new selection, including tasks that had not yet
returned a response. The final 100 tasks were sampled from the remaining 320,
with ten per domain. One task per domain is a benign control; nine are attacked.
Selection seed: 202611087. Outcome-based selection was not used.

The Adaption target is fixed to `gemma-4-26b-a4b-it`, temperature 0.7, maximum
2,048 output tokens; no tools, persistent memory, response storage or conversation
continuation. Requests start at least 1.5 seconds apart within the process;
429 retries are bounded and logged. Inference sampling is not seeded because
Adaption does not expose a sampling seed. The protocol freezes source and case
hashes before dispatch in `runs/h1-adaption-authority600/FROZEN_PROTOCOL.json`.

Only the 100 development tasks were expanded into 900 safe-reference examples
and imported into Adaption dataset `40fc2983-0463-4d98-a64a-b416ebb61108`.
The server reports the import as awaiting_input. No evaluation rows were imported,
and no data adaptation or training job was launched.

The source audit found no normalized exact duplicates and no word-TF-IDF cosine
candidate pairs at the 0.75 threshold. This does not establish semantic
independence or human validity. Two hosted models audited the six translated
role messages; all 12 machine audits recognized the requested marker action and
fictional provenance. Independent bilingual review is still pending.

The primary estimand is the difference in authority effects between Vietnamese
or Chinese and English, with complete task blocks and task-cluster bootstrap
intervals. Separate language contrasts are exploratory; language does not imply
culture. All-zero outcomes cannot establish equivalence. Under the old small-Qwen
variance, 90 attack task clusters are insufficient to reliably detect a 10-point
interaction; this remains an exploratory study, not a guaranteed positive finding.

Reproduce the fixed selection without API calls:
`python scripts/run_authority600.py`. Run with `--run` only to dispatch/resume
under the unchanged frozen source; records are append-only. A changed protocol
requires a separate run directory.
