# Agent-handoff integration smoke

Six locally orchestrated peer → worker A → worker B cases completed with 0 errors and 24 real Adaption responses. The peer used DeepSeek; both logical workers used stateless Gemma requests. Three deliberately poisoned proposals were generated by the peer as requested by the test driver; these are not spontaneous victim failures.

The first receiver was correct in 6/6 cases. The unguarded second receiver was correct in 6/6; the guarded second receiver was correct in 6/6. Receivers already had authoritative source facts. Thus this smoke test shows the envelope/routing/guard integration works on these cases, **not incremental security benefit**. Separate downstream branches are different model draws.

This early smoke assigned one task to each language, so language and task are confounded. The subsequent matched multilingual pilot fixes that design by crossing the same tasks with all three languages; its results are reported separately. No subliminal bias, token search or TruthfulQA procedure from Thought Virus is reproduced.

Recompute with `uv run python scripts/report_agent_handoff.py`. Frozen inputs, code hashes, real model requests and responses, ingress audits and both outgoing branches are preserved in `runs/agent-handoff-smoke-v1`.
