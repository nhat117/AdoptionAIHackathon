# Research reviews

Every substantive LLM judge review of this project must include a fresh web search for similar research and applicable lessons, not only inspection of our code and results.

Follow [reports/RESEARCH_REVIEW.md](reports/RESEARCH_REVIEW.md). Record primary-source links, the search scope, methodological overlap, lessons, and concrete keep/change/drop decisions in Markdown. Distinguish replication from a new contribution. An unsuccessful search is not proof of novelty.

Technical correctness, empirical findings, novelty, and spending authorization are separate conclusions. Never treat a positive judge review as permission to spend beyond an explicitly authorized cap.
